The projects

  • Budget App

    Category ledgers that refuse to overdraw, transfers between categories, and a text-mode bar chart of spending shares.

    OOPCompositionText rendering

  • Email Client

    A three-class domain model — User, Inbox, Email — where inbox operations raise exceptions instead of printing, so they can be tested.

    OOPDomain modelExceptions

  • Hash Table

    Built from scratch with separate chaining. The hash sums character codes, so anagrams collide — and the table handles it correctly.

    Data structuresCollisionsDunder methods

  • ISBN Validator

    Recomputes ISBN-10 and ISBN-13 check digits from the weighted digit sums, with every input failure given a named exception.

    ArithmeticValidationError handling

  • Polygon Area Calculator

    Square inherits from Rectangle and overrides both setters, so a square can never be silently turned into a non-square.

    InheritanceInvariantsLiskov

  • Tower of Hanoi

    An iterative solution to the textbook recursion problem, using the parity rule for the smallest disk. Optimal in 2ⁿ−1 moves.

    AlgorithmsIterationProperty tests

  • User Settings

    A case-insensitive key-value store where every operation returns its message rather than printing it, which is what makes it testable.

    DictionariesNormalisationTestability
